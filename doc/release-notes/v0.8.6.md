# Resin v0.8.6

## 节点清理

- 节点池支持批量清理选中的失效节点，保留尚未完成首次探测的节点。
- 支持手动清理参考延迟超过自定义阈值的选中节点，等于阈值或没有延迟数据的节点会保留。
- 新增服务端高延迟自动清理，默认关闭、阈值默认 `1000 ms`。开关与阈值可在节点池或系统配置中保存，关闭页面后仍由服务端执行。
- 清理会移除选中节点的所有来源订阅引用，并保留驱逐标记，避免下次订阅刷新立即重新导入。

## 区域搜索与订阅兼容

- 区域筛选支持输入中文、英文名称或地区代码搜索，并支持键盘选择。
- 完善 Shadowsocks/SIP002 链接解析，兼容可选末尾斜杠、百分号编码凭据和大写协议前缀。
- 读取旧版持久化配置时补齐新增设置的默认值，保留已保存的配置值。
