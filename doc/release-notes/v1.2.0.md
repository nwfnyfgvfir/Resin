# Resin v1.2.0

## 接入点管理（Endpoint Management）

- 可在 WebUI 或 API 中管理自定义入站接入点。
- 可针对每个接入点分别配置 管理页面 / HTTP 正向 / HTTP 反向 / SOCKS5 能力，并查看监听状态与错误信息。
- CONNECT 与 WebSocket 隧道现在会随其所属接入点一起关闭。
- 当未设置 `RESIN_PROXY_TOKEN` 时，接入点可以要求 HTTP 正向代理与 SOCKS5 携带 Platform/Account 身份；此时不校验密码。

## WebUI 改进

- 支持在订阅列表中直接切换启用状态，启用状态与刷新状态分别展示。
- 管理员令牌输入框改为掩码显示，并提供显隐切换。
- 修复长文本、徽标与请求日志相关的布局问题。

## 升级说明

> [!IMPORTANT]
> `LEGACY_V0` 已被移除。`RESIN_AUTH_VERSION` 未设置或为空时默认按 `V1` 处理；填写其他值会导致启动失败。

- 从 `LEGACY_V0` 升级前，请先在一个仍兼容的旧版本上完成客户端、`RESIN_PROXY_TOKEN` 与 Platform 名称的迁移。参见 [迁移指南](https://github.com/Resinat/Resin/blob/master/doc/v1.0.0-migration-guide.md)。
- Docker 用户必须预先发布自定义接入点端口，或改用 host 网络。
